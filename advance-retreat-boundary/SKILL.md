# Advance Retreat Boundary

## R - 原文

> 勿用有攸往。利建侯。

> 利涉大川。

> 不利涉大川。

> 征凶，无攸利。

## I - 方法论骨架

《周易》的行动词不是情绪建议，而是边界条件。“利有攸往”表示有方向地推进可行；“无攸利”表示没有值得推进的方向；“勿用”表示某类动作暂时不要启用；“利涉大川”表示可以承担重大障碍或转换；“不利涉大川”表示不宜把问题升级为大动作；“征凶”表示主动出征会带来结构性危险。

这个 skill 把用户想做的动作分成五档：进、涉险、守、待、退。然后根据处境、时位、资源、关系和风险词，给出行动许可或禁令。

## A1 - 书中的应用

### 案例 1：屯卦不许乱冲，但允许建侯

- 问题：初创局面秩序未立。
- 文本动作：“勿用有攸往。利建侯。”
- 方法论：禁止大推进，允许立组织。
- 结果：现实中不是“什么都不做”，而是把扩张改成建制。

### 案例 2：讼卦不宜涉大川

- 问题：争端可以处理，但升级成大战役危险。
- 文本动作：“利见大人，不利涉大川。”
- 方法论：找中介、权威或规则，避免重大战线。
- 结果：现实中可调解、仲裁、降级，不宜硬刚到底。

### 案例 3：益卦允许大动作

- 问题：资源增加、方向明确时，可以跨越障碍。
- 文本动作：“利有攸往，利涉大川。”
- 方法论：当信任、资源、方向匹配时，推进和跨越都可行。
- 结果：现实中可以把机会转成项目，但仍需检查承载力。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户已经知道局面大致类型，但不知道行动强度。
2. 用户在推进、等待、撤退、修复、求助之间犹豫。
3. 用户遇到“利涉大川”“不利涉大川”“无攸利”等原文。
4. 用户需要把周易判断词转成具体行动边界。

### 语言信号

- “现在该进还是退？”
- “这是不是利有攸往？”
- “能不能涉大川？”
- “无攸利是不是完全不能做？”
- “征凶但又说贞吉，该怎么行动？”

### 与相邻 skill 的区别

- 与 `line-position-timing` 的区别：后者判断时机；本 skill 输出行动许可。
- 与 `auspicious-risk-language` 的区别：后者解释判断词；本 skill把判断词落到动作边界。
- 与 `scale-and-restraint-control` 的区别：后者重点判断大小尺度和承载力。

## E - 可执行步骤

1. **写出用户想做的动作**
   - 完成标准：把动作表述为推进、涉险、守成、等待、退回、修复、求助之一。
2. **匹配边界词**
   - 完成标准：选出最相关的词组：利有攸往、利涉大川、无攸利、勿用、不利涉大川、征凶、居贞吉。
3. **检查许可条件**
   - 完成标准：说明许可条件是否满足，包括秩序、信任、资源、阶段、外部支持。
4. **给出行动分档**
   - 完成标准：输出“可做 / 小做 / 等待 / 先修复 / 不做 / 退出”，并列出下一步最小动作。

## B - 边界

### 不要在以下情况使用

- 用户要求确定未来结果，而不是行动边界。
- 高风险法律、医疗、投资问题没有专业信息。
- 用户只想看原文释义，不需要决策建议。

### 失败模式

- 看到“利”就鼓励行动，忽略后置条件。
- 看到“凶”就完全否定，忽略可修复的路径。
- 不区分“大动作”和“小动作”。

### 来源边界

本 skill 只把经文行动词转成决策边界，不提供占筮算法。
