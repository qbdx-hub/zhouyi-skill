# Stage 1 候选池：术语表

| 术语 | 工作定义 | 蒸馏用法 |
|---|---|---|
| 卦 | 一类整体处境 | 先定位问题类型 |
| 爻 | 同一处境中的具体位置/阶段 | 判断行动时机 |
| 初 | 局面初始、根部、尚未展开 | 多用于潜伏、起步、设防 |
| 二 | 局面开始进入稳定互动 | 多用于内在中位、初步可行 |
| 三 | 下卦末端，容易过门槛或失衡 | 多见厉、凶、吝 |
| 四 | 接近上层或转入外部行动 | 多需审慎承接 |
| 五 | 中心、主位、权责最大 | 多与大人、君位、核心决策相关 |
| 上 | 末端、过度、完成后的风险 | 多见悔、凶、终局反转 |
| 吉 | 条件匹配时可行 | 输出为“可做，但条件是...” |
| 凶 | 结构性危险 | 输出为“不要按当前方式做” |
| 悔 | 已有偏差但可回头 | 输出补救动作 |
| 吝 | 局促、羞困、损耗 | 输出为低收益或不舒展 |
| 无咎 | 责任风险可控 | 不等于有收益 |
| 厉 | 有危险，需警惕 | 输出风险警戒 |
| 贞 | 守正、稳定、长期坚持 | 检查原则和耐心 |
| 亨 | 通达、可流通 | 检查阻塞是否解除 |
| 孚 | 信任、诚意、可信承诺 | 检查联盟与承诺 |
| 利有攸往 | 适合有方向地前进 | 进攻/推进许可 |
| 无攸利 | 没有值得推进的方向 | 停止或重估 |
| 利涉大川 | 可承担大障碍/大转换 | 重大行动许可，但需条件 |
| 勿用 | 不要启用某动作或人 | 禁止强触发 |
