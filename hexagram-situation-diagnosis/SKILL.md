# Hexagram Situation Diagnosis

## R - 原文

> 屯：元亨，利贞。勿用有攸往。利建侯。

> 讼：有孚窒惕，中吉；终凶。

> 剥：不利有攸往。

> 复：亨。出入无疾，朋来无咎。

## I - 方法论骨架

《周易》的第一层用法是“处境命名”：不要急着给行动建议，先判断问题属于哪类局面。屯是开局混乱，蒙是认知未开，需是等待，讼是争端，师是组织化动员，比是结盟，泰是否极通塞，剥是基础剥落，复是返回正轨，困是受阻，革是改革，鼎是新秩序承载，既济是已成后的尾部风险，未济是未成前的临门风险。

这个 skill 把用户的现实问题映射到 1-3 个候选卦象簇，输出“中心张力、危险误判、下一步该调用的 skill”。它不宣布未来，而是帮助用户把混沌问题放进一个可讨论的结构。

## A1 - 书中的应用

### 案例 1：屯卦把开局难从“失败”改写为“先建组织”

- 问题：万事开头难，贸然推进会失序。
- 文本动作：“勿用有攸往。利建侯。”
- 方法论：不是停止一切，而是把大推进改成先立秩序、立负责人、立边界。
- 结果：现实分析中遇到新项目初期混乱时，应先诊断组织和规则，而不是催进度。

### 案例 2：讼卦把争端限制在可控区间

- 问题：争端有合理诉求，但拉到底会凶。
- 文本动作：“中吉；终凶。”
- 方法论：争端可以被处理，但不该被无限升级。
- 结果：现实分析中遇到纠纷，要先判断它是协商、仲裁、止损还是决裂。

### 案例 3：剥复把衰败和回归分开

- 问题：基础正在剥落时，扩张会错上加错。
- 文本动作：剥说“不利有攸往”，复说“朋来无咎”。
- 方法论：先识别是剥落期还是复归期。
- 结果：同样是困难，剥要收，复可以逐步回到正轨。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户描述一个复杂局面，希望用《周易》帮忙分类。
2. 用户不知道该先推进、等待、修复、结盟还是止损。
3. 用户已经有一个卦名，但不知道它对应的现实问题类型。
4. 用户想把古文里的卦象转成现代决策语言。

### 语言信号

- “这个局面像哪一卦？”
- “用周易帮我看看现在处境。”
- “我不是要算命，是想用卦象整理问题。”
- “这件事是屯、困、剥还是复？”
- “先给我一个周易式诊断。”

### 与相邻 skill 的区别

- 与 `line-position-timing` 的区别：本 skill 判断是哪类局面；后者判断处于局面内部哪个阶段。
- 与 `advance-retreat-boundary` 的区别：本 skill 先定位；后者决定进退动作。
- 与 `auspicious-risk-language` 的区别：本 skill 处理卦象；后者翻译吉凶悔吝等判断词。

## E - 可执行步骤

1. **收集处境事实**
   - 完成标准：列出目标、压力来源、参与者、资源、已发生变化、用户当前想采取的动作。
2. **匹配候选卦象簇**
   - 完成标准：给出 1-3 个候选处境，例如开局难、等待、争端、联盟、闭塞、剥落、修复、改革、完成前后风险。
3. **抽取中心张力**
   - 完成标准：说明局面真正矛盾是什么，例如“秩序未立却想推进”“争端可处理但不能拖到底”“基础剥落不宜扩张”。
4. **输出诊断卡**
   - 完成标准：包含候选卦象、证据、最危险误判、建议下一步调用的 skill、以及不确定性。

## B - 边界

### 不要在以下情况使用

- 用户要求随机起卦、预测彩票、断定婚姻生死或给确定未来。
- 用户只需要原文翻译，不需要处境分析。
- 用户面对法律、医疗、财务高风险问题却要求替代专业意见。

### 失败模式

- 把任何困难都说成“困卦”，失去区分度。
- 只按用户情绪选卦，不按事实结构选卦。
- 给出卦名后立刻下结论，没有说明证据和边界。

### 来源边界

本 skill 只依据当前 EPUB 中的六十四卦经文；不调用后世象数起卦、纳甲、爻变规则。
