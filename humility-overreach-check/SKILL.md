# Humility Overreach Check

## R - 原文

> 上九：亢龙有悔。

> 羝羊触藩，羸其角。

> 丰其屋，蔀其家。

> 既济：亨，小利贞，初吉终乱。

## I - 方法论骨架

《周易》反复提醒：强不等于可以继续强推，高位不等于无风险，成功不等于结束。过盛的危险来自三种错觉：以为力量越大越好，以为高位可以不收束，以为已经完成就不用戒备。

这个 skill 专门检查“成功后的风险”：是否已经从可进变成该收，从主导变成压迫，从丰盛变成遮蔽，从既济变成终乱。

## A1 - 书中的应用

### 案例 1：乾上九

- 问题：力量达到高位后继续上冲。
- 文本动作：“亢龙有悔。”
- 方法论：高位的风险不是无能，而是过度。
- 结果：现实中成功后要检查退出、授权、收束和节制。

### 案例 2：大壮的羊角卡住

- 问题：强力推进撞上边界。
- 文本动作：“羝羊触藩，羸其角。”
- 方法论：力量越大，卡住时损伤越大。
- 结果：现实中强推前要看制度、资源和关系边界。

### 案例 3：丰与既济的尾部风险

- 问题：丰盛、完成后反而遮蔽和混乱。
- 文本动作：丰上六“丰其屋，蔀其家”；既济“初吉终乱”。
- 方法论：光大之后要防遮蔽，已成之后要防失序。
- 结果：现实中项目上线、胜利、升职、融资后更要复盘。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户已经取得阶段胜利，想继续加码。
2. 用户处在权力、名声、资源或情绪高位。
3. 用户担心“太顺了会不会有问题”。
4. 用户读到乾、大壮、丰、既济等文本，想转成现代风险检查。

### 语言信号

- “这是不是亢龙有悔？”
- “我现在是不是该收一点？”
- “成功之后还要不要继续冲？”
- “大壮为什么反而危险？”
- “既济的初吉终乱怎么用在项目里？”

### 与相邻 skill 的区别

- 与 `line-position-timing` 的区别：本 skill 聚焦高位、过盛、完成后的风险。
- 与 `scale-and-restraint-control` 的区别：后者处理大小尺度；本 skill 处理强势状态下的过度。
- 与 `advance-retreat-boundary` 的区别：本 skill 先检查是否过盛，再决定行动边界。

## E - 可执行步骤

1. **识别过盛信号**
   - 完成标准：列出权力、资源、速度、情绪、承诺、舆论中哪些已经过高。
2. **检查卡点**
   - 完成标准：指出可能像“触藩”的边界：制度、现金流、团队承载、关系反弹、合规风险。
3. **判断是否该收**
   - 完成标准：给出继续推进、降速、分权、复盘、止盈、退出或暂停的建议。
4. **设计谦抑动作**
   - 完成标准：给出一个可以立刻降低过盛风险的小动作，例如延迟发布、减少承诺、引入反对意见。

## B - 边界

### 不要在以下情况使用

- 用户处在明显初创、低能量、无资源阶段，核心问题不是过盛。
- 用户只想获得情绪鼓励。
- 用户需要精确财务或法律结论。

### 失败模式

- 把所有成功都说成危险，压制正常进展。
- 只说“谦虚”，不指出具体过盛变量。
- 忽略用户仍可能需要推进的窗口。

### 来源边界

本 skill 依据经文中过盛反转的结构，不等同于完整儒家修身解释。
