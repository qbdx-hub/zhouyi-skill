# Line Position Timing

## R - 原文

> 初九：潜龙勿用。

> 九三：君子终日乾乾，夕惕若厉，无咎。

> 上九：亢龙有悔。

> 鸿渐于干。鸿渐于磐。鸿渐于陆。

## I - 方法论骨架

《周易》的六爻可以蒸馏成一个时位诊断表。同一目标，在不同位置上的建议不同：初位多是萌芽和根部，二位开始进入稳定互动，三位靠近门槛、容易冒进，四位接近外部或上位、需要承接，五位是核心权责位，上位是末端、过盛或完成后的反转点。

行动是否正确，不只看“做什么”，还看“现在处在哪个位置”。乾卦把力量从潜伏、显现、警惕、跃迁、飞腾到亢进完整展开；渐卦把推进写成逐步迁移；既济、未济则提醒完成前后都有尾部风险。

## A1 - 书中的应用

### 案例 1：乾卦的阶段递进

- 问题：有能力不等于随时都该用。
- 文本动作：初位“潜龙勿用”，五位“飞龙在天”，上位“亢龙有悔”。
- 方法论：初位要蓄势，五位可承担，上位要收。
- 结果：现实中判断一个人或项目是否该出场，要先看阶段。

### 案例 2：渐卦的渐进推进

- 问题：关系、事业或制度成长不能跳级。
- 文本动作：鸿从水边到磐石、陆地、树木、山陵逐步上升。
- 方法论：每一步有自己的落点，先稳住当前承载点。
- 结果：现实中遇到长期项目，应看是否越级承诺。

### 案例 3：未济的临门风险

- 问题：快完成时以为已经安全。
- 文本动作：“小狐汔济，濡其尾”。
- 方法论：临门阶段的风险常在尾部，而不是开头。
- 结果：现实中在交付、上线、成交前要专门检查尾部风险。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户问现在该动、该等、该收、该跃迁还是该止损。
2. 用户把同一个行动放在不同时间点，想知道为什么结果可能不同。
3. 用户做项目、关系、谈判、职业选择时，需要判断阶段成熟度。
4. 用户给出某一爻，但想把爻位转成现代行动判断。

### 语言信号

- “现在是不是还没到时候？”
- “我处在初爻还是上爻？”
- “为什么现在做会凶，以后做可能吉？”
- “这事是不是已经亢龙有悔了？”
- “未济是不是说明快完了反而要小心？”

### 与相邻 skill 的区别

- 与 `hexagram-situation-diagnosis` 的区别：本 skill 在已知或大致知道处境后，判断阶段位置。
- 与 `advance-retreat-boundary` 的区别：本 skill 诊断时机；后者给进退动作。
- 与 `humility-overreach-check` 的区别：后者专门处理过盛、高位、成功后的失控。

## E - 可执行步骤

1. **确定当前阶段**
   - 完成标准：把用户处境放入初、二、三、四、五、上之一，并说明依据。
2. **判断位置风险**
   - 完成标准：指出主要风险是过早、门槛冒进、承接不足、高位责任、末端过度还是尾部风险。
3. **匹配行动强度**
   - 完成标准：给出适合当前阶段的动作，例如蓄势、试探、求助、承接、主导、收束。
4. **给出换位条件**
   - 完成标准：说明什么证据出现后，才算进入下一阶段。

## B - 边界

### 不要在以下情况使用

- 用户要完整起卦、变卦、占筮算法。
- 用户只问某个卦名是什么意思，不涉及阶段。
- 用户要求确定日期或精确预测结果。

### 失败模式

- 把初爻简单说成差，上爻简单说成好。
- 忽略卦象差异，只套固定时间表。
- 不说明从当前阶段进入下一阶段需要什么证据。

### 来源边界

本 skill 抽取的是经文中反复出现的时位结构，不等同于完整易学爻位体系。
